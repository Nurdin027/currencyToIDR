# Currency To IDR

Simple Chrome extension

### Konfigurasi
- Klik Ekstensi
- Di popup yang muncul, klik **Settings**
- di halaman **Extension Configuration**, isi **Exchangerate Key**
- Isi **Currencyfreaks Key** (optional)
- Klik **Save**

### Cara penggunaan:

- Block text yang mengandung angka yang ingin di konversi
- Klik kanan
- Klik **Dollar to IDR**
- Akan muncul popup berwarna biru di kanan bawah
